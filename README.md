# CCNA Study Project

Этот репозиторий - рабочая база для подготовки к CCNA: конспекты, лабораторные, конфиги, проверочные вопросы и повторение.

## Главный план

- [STUDY_PLAN.md](STUDY_PLAN.md) - расписание подготовки с 4 мая по 28 августа 2026.

## Структура

- `notes/` - конспекты по темам и урокам.
- `labs/` - разбор лабораторных работ и отчеты.
- `packet-tracer/` - заметки по топологиям Packet Tracer без бинарных `.pkt/.pka` файлов.
- `cheatsheets/` - короткие шпаргалки по командам, протоколам и таблицам.
- `quizzes/` - ответы, ошибки и разборы квизов.
- `flashcards/` - карточки для повторения.
- `configs/` - фрагменты конфигураций Cisco IOS.
- `resources/` - ссылки и внешние материалы.
- `review/` - еженедельные итоги, пробные экзамены и слабые места.

## Рабочий формат

Основной формат материалов - Markdown. Для каждого урока удобно создавать файл по шаблону:

```md
# Skill XX Lesson YY - Название

## Кратко

## Ключевые понятия

## Команды

## Ошибки и вопросы

## Что повторить
```
