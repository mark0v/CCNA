# CCNA Study Project

Этот репозиторий - рабочая база для подготовки к CCNA: конспекты, лабораторные, конфиги, проверочные вопросы и повторение.

## Главный план

- [STUDY_PLAN.md](STUDY_PLAN.md) - расписание подготовки с 4 мая по 28 августа 2026.

## Структура

- `articles/` - обработанные статьи по календарю: `YYYY-MM/week-XX/topic.md`.
- `notes/` - конспекты по темам и урокам.
- `labs/` - разбор лабораторных работ и отчеты.
- `packet-tracer/` - заметки по топологиям Packet Tracer без бинарных `.pkt/.pka` файлов.
- `cheatsheets/` - короткие шпаргалки по командам, протоколам и таблицам.
- `quizzes/` - ответы, ошибки и разборы квизов.
- `flashcards/` - карточки для повторения.
- `configs/` - фрагменты конфигураций Cisco IOS.
- `resources/` - ссылки и внешние материалы.
- `review/` - еженедельные итоги, пробные экзамены и слабые места.
- `templates/` - шаблоны Markdown-файлов.

## Рабочий формат

Основной формат материалов - Markdown. Для каждого урока удобно создавать файл по шаблону:

```md
# Skill XX Lesson YY - Название

## Кратко

## Ключевые понятия

## Команды

## Ошибки и вопросы

## Что повторить
```

## Формат статей

Статьи складываем в `articles/YYYY-MM/week-XX/`. Имя файла делаем коротким и понятным, например `osi-model.md`, `switching-basics.md`, `subnetting-vlsm.md`.

Каждая статья в проекте должна содержать:

- краткое саммари;
- ключевые идеи;
- конспект без лишней воды;
- важные термины или команды;
- несколько вопросов с ответами по самой статье;
- блок для повторения позже.

Базовый шаблон: [templates/article-note.md](templates/article-note.md).

## Как присылать статью

Лучший вариант для экономии токенов: присылай ссылку на страницу и коротко пиши, к какой теме/неделе ее привязать. Я сам открою страницу, вытащу важное и сделаю Markdown-файл.

Если сайт закрыт, требует логин или плохо открывается, лучше прислать не HTML, а очищенный текст из режима чтения браузера: заголовок, ссылка, основной текст статьи. HTML стоит присылать только если текст нельзя нормально скопировать: он обычно сильно шумный и расходует больше токенов.

Для закрытого курса первая строка присланного текста считается названием статьи. По ней создается имя Markdown-файла в `kebab-case`, например `What is a Network?` -> `what-is-a-network.md`.
