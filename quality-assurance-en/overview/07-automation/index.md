## Learning Path

1. Learn one programming language and Git.
2. Automate stable API checks.
3. Learn browser automation and locator strategy.
4. Organize tests with fixtures, helpers, and page or component objects.
5. Run tests in containers and CI.
6. Add reports, logs, screenshots, traces, and artifacts.
7. Improve reliability, execution time, and maintenance cost.

## Automation Focus

Automation is valuable when a check is repeatable, deterministic, and worth maintaining.

Good candidates:

- smoke and regression;
- API contracts;
- critical user flows;
- repetitive data checks;
- cross-browser coverage;
- load and performance scripts.

Poor candidates:

- one-time checks;
- rapidly changing behavior;
- subjective usability evaluation;
- exploratory investigation.

The goal is not to automate every manual test. The goal is fast, trustworthy feedback.
