# Levels of Testing

## Summary

Levels of Testing is a section about testing levels in the software testing hierarchy.

It collects articles about how testing moves from individual parts of the system to a fully integrated product and then to acceptance by users or customers.

## Key Points

- Testing levels help clarify what is being tested at each stage.
- Unit testing checks the smallest units of code.
- Integration testing checks interactions between modules/components.
- System testing checks the whole integrated system.
- Acceptance testing checks product readiness for users/customers.
- Different levels find different types of defects.

## Notes

This section currently contains:

The main idea of testing levels: quality is checked progressively. First the team verifies individual units, then their interactions, then the whole system against requirements, and finally whether users/customers are ready to accept the product.
