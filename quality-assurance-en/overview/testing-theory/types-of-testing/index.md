# Types of Testing

## Summary

Types of Testing is a section about different testing types QA uses depending on the testing goal, build state, type of change, and product risks.

It contains articles about functional and non-functional testing, regression testing, smoke/sanity testing, and the difference between static and dynamic testing.

## Key Points

- Different testing types answer different questions.
- Functional testing checks what the system does.
- Non-functional testing checks how the system behaves.
- Smoke and sanity testing help quickly evaluate a build and specific changes.
- Regression testing protects existing functionality from unexpected side effects.
- Static and dynamic testing differ by whether software is executed during testing.
