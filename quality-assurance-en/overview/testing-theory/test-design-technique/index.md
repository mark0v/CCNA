# Test Design Technique

## Summary

Test Design Technique is a section for test design techniques.

It will collect approaches that help QA engineers create test cases systematically instead of guessing randomly. These techniques help choose checks based on requirements, risks, input data, system states, and expected behavior.

## Key Points

- Test design techniques help create stronger test cases.
- They reduce random testing and improve coverage.
- They help choose representative inputs instead of exhaustive testing.
- This section is useful for manual QA, automation QA, and interview preparation.
