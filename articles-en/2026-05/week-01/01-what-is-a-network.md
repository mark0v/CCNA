## Summary

A network is a way for devices to exchange data. At the simplest level, one machine wants to send information to another machine. As the number of devices, security requirements and business needs grows, switches, routers, firewalls and wireless access points become necessary.

Main idea: networking does not start with magic or complex diagrams. It starts with a basic question: how do we move data from one device to another reliably, quickly and safely?

## Key Points

- A network is a group of devices that communicate with each other.
- Data is sent in small pieces called packets.
- A switch connects devices inside one local network.
- A router connects different networks together.
- The internet is a massive system of interconnected networks.
- A firewall filters traffic and protects the network.
- A wireless access point lets devices join the network without a cable.
- A home all-in-one router often combines several roles, but business networks usually separate them.

## Notes

### What Even Is a Network?

A network is a set of devices that talk to each other and move information from point A to point B.

An online game is a useful example. When a player takes an action, the device sends a small piece of data through the home network, out to the internet, to a remote server and then toward other players.

### Core Device Roles

- `Switch` - connects local devices.
- `Router` - connects different networks.
- `Firewall` - allows good traffic and blocks bad traffic.
- `Wireless access point` - provides WiFi access to the network.

### Home vs Business

Home networks often use one device that combines modem, router, switch, wireless access point and basic firewall functions. Business networks usually split those functions because they have more users, more traffic and higher security expectations.

### What does a switch do?

It connects multiple devices inside one local network.

### How is a router different from a switch?

A switch connects devices in one network. A router connects different networks.
