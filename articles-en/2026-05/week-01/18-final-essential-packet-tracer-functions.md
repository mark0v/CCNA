## Summary

You do not need to know every Packet Tracer feature. You need the essentials: make the workspace readable, use labels and notes wisely, understand Realtime vs Simulation mode, delete mistakes and save your work.

Main idea: use Packet Tracer to understand the network, not to decorate the workspace.

## Key Points

- Port labels can help beginners see connections.
- Too many automatic labels can clutter the topology.
- Notes are useful for manually documenting IPs and roles.
- Shapes and backgrounds can help, but can also waste time.
- Clear diagrams beat pretty diagrams.
- The delete tool keeps the workspace clean.
- Device model labels can be useful or noisy.
- Realtime mode behaves like a normal running network.
- Simulation mode slows traffic down so you can inspect packet flow.
- Packet Tracer prepares learners for real tools like Wireshark.
- Saving work is essential for repeated practice.

## Notes

### Workspace Clarity

Useful workspace tools:

- port labels;
- notes;
- simple shapes;
- delete tool;
- alignment helpers.

Use them only when they make the topology easier to understand.

### Realtime vs Simulation

Realtime:

```text
Network behaves normally and quickly.
```

Simulation:

```text
Traffic can be stepped through and inspected.
```

Simulation mode is one of Packet Tracer's best teaching features.

### Save Your Labs

Networking skill grows through repetition:

```text
Build -> test -> break -> fix -> save -> return later
```

## Commands / Terms

| Term | Meaning |
| --- | --- |
| Realtime mode | Normal running network mode. |
| Simulation mode | Packet-by-packet teaching mode. |
| Note | Manual text annotation. |
| Port label | Interface label shown near a connection. |

## Questions

### Why use Simulation mode?

It shows how traffic moves step by step.

### Why not focus on making the lab beautiful?

Because the goal is learning and troubleshooting, not visual decoration.
