# Test Design Technique

## Summary

Test Design Technique - это раздел для техник проектирования тестов.

Здесь будут собраны подходы, которые помогают QA не просто придумывать проверки наугад, а системно выбирать test cases на основе требований, рисков, входных данных, состояний системы и expected behavior.

## Key Points

- Test design techniques помогают создавать более сильные test cases.
- Они уменьшают количество случайного testing и повышают coverage.
- Техники помогают выбирать representative inputs вместо exhaustive testing.
- Раздел будет полезен для manual QA, automation QA и подготовки к interviews.
