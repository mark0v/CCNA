# Test Documentation

## Summary

Test Documentation - это раздел про документы и артефакты, которые помогают QA-команде планировать, выполнять, отслеживать и объяснять тестирование.

Документация в testing нужна не ради бюрократии. Ее задача - сделать процесс понятным:

- что тестируем;
- зачем тестируем;
- как тестируем;
- кто отвечает за работу;
- какие риски есть;
- какие результаты получили.

## Common QA Documents

В этом разделе будут собраны статьи про:

- Test Plan;
- Test Strategy;
- Test Cases;
- Checklists;
- Bug Reports;
- Test Summary Reports;
- Traceability Matrix;
- Test Closure Reports.

## Key Idea

Хорошая тестовая документация помогает команде видеть общий план и принимать решения на основе фактов, а не догадок.

Главная мысль:

> Documentation should support testing, not slow it down.
