# Levels of Testing

## Summary

Levels of Testing - это раздел про уровни тестирования в software testing hierarchy.

Здесь собраны статьи о том, как testing движется от отдельных частей системы к полностью собранному продукту и затем к acceptance со стороны users или customer.

## Key Points

- Testing levels помогают понять, что именно проверяется на каждом этапе.
- Unit testing проверяет smallest units of code.
- Integration testing проверяет взаимодействие modules/components.
- System testing проверяет whole integrated system.
- Acceptance testing проверяет readiness продукта для users/customer.
- Разные levels находят разные types of defects.

## Notes

В этом разделе сейчас находятся:

- Integration Testing;
- System Testing;
- System vs Integration Testing;
- Acceptance Testing / UAT.

Главная идея уровней тестирования: качество проверяется постепенно. Сначала команда убеждается, что отдельные units работают, затем что они правильно взаимодействуют, затем что весь system соответствует requirements, и наконец что users/customer готовы принять продукт.
