# Types of Testing

## Summary

Types of Testing - это раздел про разные виды тестирования, которые QA использует в зависимости от цели проверки, состояния build, типа изменений и рисков продукта.

Здесь собраны статьи о functional и non-functional testing, regression testing, smoke/sanity testing, а также о различии static и dynamic testing.

## Key Points

- Разные виды testing отвечают на разные вопросы.
- Functional testing проверяет, что система делает.
- Non-functional testing проверяет, как система работает.
- Smoke и sanity testing помогают быстро оценивать build и конкретные changes.
- Regression testing защищает existing functionality от unexpected side effects.
- Static и dynamic testing отличаются тем, выполняется ли software during testing.

Главная идея: QA не использует один универсальный тип testing для всех ситуаций. Хороший тестовый подход собирается из нескольких видов testing, которые вместе покрывают product risks.
