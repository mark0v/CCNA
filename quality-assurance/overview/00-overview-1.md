## 🎯 Рекомендуемый порядок изучения

### Фаза 1 — Закрыть базовые пробелы (1–2 месяца)
1. ✅ Теория тестирования — закрыть все "Not Started" из IDP
   - Test Strategy, Test Coverage, Risks, Test Impact, UML, Metrics
2. ✅ Web тестирование — Архитектура, HTTP, Network, DevTools
3. ✅ API — REST vs SOAP, JSON/XML, Postman

### Фаза 2 — Специализации (2–3 месяца)
4. ✅ Mobile тестирование — iOS/Android specifics, логи, эмуляторы
5. ✅ Базы данных — SQL JOINs, INSERT, UPDATE, DB Testing
6. ✅ Performance — Load, Stress, Stability, Tools

### Фаза 3 — Продвинутый уровень (3–4 месяца)
7. ✅ Automation — Основы, Selenium/Playwright/Cypress
8. ✅ CI/CD, Git, Docker
