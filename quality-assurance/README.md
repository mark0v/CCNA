# Quality Assurance

Здесь будут материалы по тестированию: теория, чек-листы, практические заметки, инструменты и разборы реальных QA-задач.

Пока раздел подготовлен как отдельное направление на том же уровне, что и `CCNA` и `Englishe`.

## Материалы

- [QA fundamentals questions](01-qa-fundamentals-questions.md) - базовые вопросы по QA-процессам, документации, видам тестирования и тест-дизайну.
- [Web, Desktop и REST API questions](02-web-api-questions.md) - проверки API-контрактов, HTTP, Postman, cookies, storage и cache.
- [Real-time и client-server questions](03-realtime-client-server-questions.md) - client-server архитектура, WebSocket, sync, reconnect, latency и error handling.
- [Mobile testing questions](04-mobile-questions.md) - native, web, PWA, hybrid и cross-platform приложения с QA-фокусом.
- [Database and SQL questions](05-database-sql-questions.md) - SQL, реляционные и NoSQL базы, ключи, JOIN, UNION и backend verification.
